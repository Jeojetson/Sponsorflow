# Calendar exports

SponsorFlow generates standard iCalendar (`.ics`) files in the browser. No calendar credentials or account access are requested.

## Entire timeline

Use **Download calendar** above the planner or inside the Calendar view. The file contains every non-archived task on the selected timeline that has a start date or due date.

## One task

Open a dated task and select **Add to calendar (.ics)**, or select `.ics` beside an item in the Calendar agenda.

## Importing

- **Apple Calendar:** open the downloaded `.ics` file and choose the destination calendar.
- **Microsoft Outlook:** open or import the `.ics` file and save the events.
- **Google Calendar:** open Calendar settings, choose **Import & export**, and import the `.ics` file.

The export is a snapshot. Editing a SponsorFlow task later does not automatically update an event that was previously imported; download and import a new file when the plan changes materially.
