# ASME Indy Workspace · SponsorFlow 1.1

A free GitHub Pages + Google Apps Script system for Purdue Indianapolis ASME:

- sponsor outreach and officer review;
- project planning and team timelines;
- parts, purchasing, funding, and progress tracking;
- a shared editable calendar;
- live `.ics` subscriptions for club, important dates, teams, and timelines.

See `UPGRADE.md` for installation and `SECURITY.md` for access limitations.
