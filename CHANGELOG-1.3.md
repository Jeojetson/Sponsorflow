# SponsorFlow 1.3 — Workspace Refresh

## Custom shared calendars

Members can create, edit, view, subscribe to, and remove custom calendars from the Calendar page.

A custom calendar can:

- Include any combination of active subteams.
- Include the general club timeline.
- Show all selected dates or only important dates and milestones.
- Use a recognizable accent color.
- Produce its own live read-only iCalendar subscription URL.

Removing a custom calendar archives only the saved view. It never deletes or moves the underlying tasks and events.

## Light and dark themes

Every GitHub Pages screen now includes a theme control. The selected theme is remembered on that browser, and the first visit follows the device preference.

The refresh includes theme-aware:

- Navigation
- Forms and inputs
- Planner boards and task cards
- Calendar grids and agendas
- Sponsor outreach panels
- Dialogs
- Tables and analytics
- Status and verification surfaces

## Mobile application layout

Phones now receive a dedicated mobile layout with:

- A compact top bar.
- A persistent five-tab bottom navigation bar.
- Full-screen task and event editors.
- Agenda-first calendar presentation.
- Contained horizontal scrolling for dense month and Kanban views.
- Safe-area spacing for modern iPhones and Android devices.
- Larger touch targets and simplified action stacking.

## Interface consistency

- Rebuilt the calendar month navigation as one aligned segmented control.
- Standardized button heights, border radii, surfaces, focus rings, and spacing.
- Added theme-aware background texture and restrained accent glow.
- Fixed page-level overflow on narrow screens.
- Improved calendar identity and selector alignment.
- Improved dark-mode coverage for Kanban columns, funding cards, tables, dialogs, and outreach components.
- Consolidated calendar management into clear primary actions.

## Google Sheet change

Version 1.3 adds one sheet:

`Planner Calendars`

It stores custom calendar definitions only. Existing teams, timelines, tasks, events, outreach requests, sponsors, comments, funding research, and live feeds are preserved.
