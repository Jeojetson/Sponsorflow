# SponsorFlow v8 changelog

## Live subscriptions

- Added an Apps Script `text/calendar` endpoint.
- Added stable event UIDs, sequence values, last-modified timestamps, and live task links.
- Added Club-wide, Important Dates, team, and timeline feed scopes.
- Added a subscription center with copy and `webcal:` launch actions.

## Calendar editing

- Added calendar-day `+` controls.
- Added a dedicated **+ Add event** action.
- Calendar events open the full task editor.
- Added an explicit **Important date** field.
- Added timeline selection when creating a task from the club-wide portfolio.

## Club-wide portfolio

- Club-wide now defaults to an aggregate portfolio containing every active team timeline.
- Finance & Sponsorship funding details are included in metrics, board, timeline, calendar, table, insights, CSV exports, and calendar exports.
- Aggregate cards and calendar items display their owning team.

## Quality and compatibility

- Preserved all existing planner and sponsor data.
- Updated asset cache keys to v8.
- Kept the existing GitHub Pages and Apps Script architecture.
